# Security / 安全

Do not put credentials, private correspondence or unpublished research in public issues. Report a suspected vulnerability without exploit details through GitHub's private vulnerability reporting when enabled, or contact the maintainer through the repository profile. No response-time guarantee is made.

不要在公开 issue 放入凭据、私人通信或未公开研究。漏洞请在启用 GitHub 私密报告后使用该功能，或通过仓库维护者公开资料联系；公开报告避免放入利用细节，不承诺固定响应时限。

The public data snapshot contains third-party URLs. Follow them with normal browser precautions; an archived URL is not an endorsement. The opt-in link checker follows HTTP(S) redirects and should run only on reviewed public URLs, never on an untrusted pull request with access to private networks or secrets. CI does not run it automatically.

数据含第三方网址，存档不代表背书。外链工具跟随 HTTP(S) 重定向，仅应对审阅后的公开链接运行，不能在可访问内网或凭据的环境直接检查不可信 PR。CI 不自动运行外链工具。
