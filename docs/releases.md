## Types for future releases / 未来版本类型

These categories describe intended uses, not a list of releases already published. / 以下分类说明用途，不代表这些版本均已发布。

| Type / 类型 | Purpose / 用途 |
| --- | --- |
| Research Snapshot / 研究快照 | A dated account of selected public research, scope and limitations / 选定公开研究的阶段记录，注明范围与限制 |
| Methodology Update / 方法更新 | Changes to evidence, chronology, translation or correction guidance / 证据、编年、翻译或勘误规范的变化 |
| Archive Statistics Update / 档案统计更新 | Counts with collection boundaries, sync date and snapshot date / 附计数边界、同步日和快照日的统计 |
| Public Data Snapshot / 公开数据快照 | Only an actual reviewed, licensed set of public structured files / 仅用于真实完成审查并明确许可的公开结构化文件 |
| Research Note / 研究札记 | A focused question or provisional interpretation linked to evidence / 关联证据的具体问题或暂定解释 |

A label such as **2026-09 Research Snapshot** is a naming example only. Use it only for a matching release; retain the actual name and tag of existing releases. Describe totals as totals, and identify a real comparison baseline before claiming additions.

**2026-09 Research Snapshot** 只是命名示例；仅在实际发布相应内容时使用，已有版本继续保留真实名称与标签。总量应标为总量，只有存在真实比较基线时才统计新增。

A public data snapshot must meet the [data release policy](data-release-policy.md). This documentation update creates no new release and assigns no new data license.

公开数据快照须符合[数据发布政策](data-release-policy.md)。本次文档更新不创建新 release，也不指定新的数据许可。
