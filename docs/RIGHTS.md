# Rights boundary / 权利边界

| Material / 材料 | Treatment / 处理 |
| --- | --- |
| Original software / 原创代码 | MIT; dependencies retain upstream notices / 依赖保留上游声明 |
| Original metadata and research / 原创编目与研究 | CC BY 4.0; preserve authorship and review state / 保留作者与审校状态 |
| Third-party titles, quotes, works / 第三方标题、引文、作品 | Rights reserved by original holders / 原权利人保留权利 |
| Historical media / 历史图片与影音 | Not bundled; inventory only / 不随库分发，仅保存清单 |
| Private archive and research drafts / 私有档案及草稿 | Excluded / 排除 |

The source distribution references media hosted on the existing public site. The Worker redirects media requests to that origin; it does not copy the media into this repository. Availability depends on that origin. This is not an offline preservation package. The inventory in [public-assets.json](public-assets.json) records paths, byte sizes and historical hashes, not a new copyright grant or a fresh network verification. Asset tests compare catalogue metadata to that inventory; optional bundled assets are byte-verified.

源码版本引用现有公开站点的媒体，Worker 将媒体请求重定向至原站，并不将媒体复制进仓库。媒体可用性依赖原站，本库不是离线保存包。[媒体清单](public-assets.json)记录路径、大小与历史哈希，不代表新增授权或本轮联网核验。测试对比编目与清单，文件实际存在时才验证字节。

Report a rights concern with a stable record ID, affected URL and the basis of the request. Do not attach private documents or complete copyrighted texts to public issues. Maintainers can remove an asset reference without erasing the historical record of a correction.

权利问题请提供稳定 ID、链接及请求依据，不要在公开 issue 附上私人文件或完整受保护原文。维护者可撤下媒体引用，同时保留更正历史。
