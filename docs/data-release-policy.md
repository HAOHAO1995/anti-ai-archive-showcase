# Public data release policy / 公开数据发布政策

A selective snapshot of the accepted November19 website is now available in [data](../data/manifest.json), with [documented structure](DATA_MODEL.md), stable IDs, JSON/CSV and checksums. Original metadata and research use [CC BY 4.0](../DATA_LICENSE.md). Software uses [MIT](../LICENSE). The complete internal archive, private notes, credentials and later unaccepted research remain excluded.

已验收的 11 月 19 日网站选择性快照现已提供 JSON/CSV、稳定 ID、数据模型与校验和。原创编目与研究采用 CC BY 4.0，软件采用 MIT。完整内部库、私人笔记、凭据及后续未验收研究均排除。

A future release requires an explicit accepted snapshot, evidence and language checks, rights review, reproducible export and corrected counting. Preserve prior versions and distinguish additions from corrections. Third-party availability does not grant redistribution rights. No automatic site deployment or GitHub release is performed by CI.

后续发布须明确验收快照，检查证据、语言、权利、可复现导出与统计，保留旧版并区分新增与更正。原站可访问不代表获得转载权；CI 不自动部署站点或创建 GitHub 正式版本。
