# Public Data Release Policy / 公开数据发布政策

[Project overview / 项目首页](../README.md) · [Citation / 引用](citation.md) · [Release types / 发布类型](releases.md)

## Current scope / 当前范围

This repository is the public research showcase for ANTI-AI ARCHIVE. The complete internal dataset is not public here. The repository contains selected descriptions, methods, notes, statistics, citation metadata and visuals; it currently provides no complete dataset download.

本仓库是 ANTI-AI ARCHIVE 的公共研究展示入口。完整内部数据集目前不在此公开；现有材料包括选定介绍、方法、笔记、统计、引用元数据和视觉材料，当前没有完整数据集下载。

## Selected future snapshots / 未来选定快照

Selected structured public snapshots may be considered as the archive develops. This is a release policy, not an announcement of an available dataset, a promised schedule or a new reuse license.

未来可能随研究进展考虑发布经过筛选的结构化公开快照。本文件是发布政策，不代表数据集已经可用、不承诺发布日程，也不授予新的复用许可。

Each public snapshot should identify: / 每份公开快照应注明：

- **Scope / 范围:** included collections, selection criteria and exclusions / 收录集合、筛选条件及排除范围。
- **Date / 日期:** evidence coverage, snapshot date and release date, distinguished / 区分证据覆盖、快照及发布日期。
- **Fields / 字段:** definitions, stable IDs, relationships, date precision and missing values / 字段定义、稳定编号、关系、日期精度和缺失值。
- **Known limitations / 已知限制:** coverage gaps, attribution, allegations versus findings, source review and translation review / 覆盖缺口、归属、指控与认定、来源核读与译文审校。
- **Citation requirements / 引用要求:** author, project, version and source attribution / 作者、项目、版本及来源归属。
- **Rights and license / 权利与许可:** explicit maintainer-approved terms for the released material / 由维护者明确批准、适用于发布材料的条款。

## Publication boundaries / 公开边界

Do not publish private drafts, internal research datasets, unpublished source notes, private automation workflows or credentials. Do not improperly redistribute personal information, restricted materials or copyrighted works. Publication on a source website is not blanket permission to redistribute its contents.

不公开私有草稿、内部研究数据集、未公开来源笔记、私有自动化工作流或凭据。不不当重新分发个人信息、受限材料或版权作品；来源网站公开可见不代表可以整体转载。

Where appropriate, source URLs and descriptive metadata can be included, with original-language titles, attribution and rights information preserved. Catalogue records do not imply full-text preservation or redistribution. Review proposed snapshots before release; do not label unknown review states as verified.

适当情况下可公开来源网址和描述性元数据，保留原语言标题、归属及权利信息。目录条目不表示保存或重新分发全文。发布前审查拟公开的快照，不将未知审查状态标为已核实。
